# read-fast output schema

Produce one Markdown overview with these sections.

## 1. One-sentence conclusion

State the main takeaway in one plain sentence.

## 2. What it is about

In two or three sentences, give the background and the problem the source addresses.

## 3. Core concepts

Explain only the concepts needed to follow the main argument. Keep definitions short and concrete.

## 4. Main argument or process

Walk through the main line, not every section. Preserve the reasoning chain so the reader does not get a wrong impression.

## 5. Key conclusions

List the conclusions the reader should remember.

## 6. Likely misunderstandings

Note the one or two places a quick reader is most likely to misread.

## 7. If you want to go deeper

Point to the source sections worth rereading, or recommend `/read-standard`.

## Output location and naming

- Root: `.reader/quick/`
- Session folder: `<YYYY-MM-DD>-<slug>/`
- Markdown: `<YYYY-MM-DD>-<slug>.md`
- Images: `assets/`
- Keep Latin titles as lowercase hyphenated slugs; keep Chinese titles in the filename with illegal characters removed.
