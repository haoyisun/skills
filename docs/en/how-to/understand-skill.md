# How to understand an agent skill

1. Install the `skill-explainer` skill.
2. Invoke `$skill-explainer`.
3. Provide a skill name, a `SKILL.md` path, or a description.
4. Ask it to read the whole `SKILL.md` first, then `references/` and `scripts/` only as needed.
5. Ask for usage triggers, inputs and outputs, risks, and a minimal invocation.

Frontmatter alone is often misleading. This skill's job is to read the entry point, not to guess.
