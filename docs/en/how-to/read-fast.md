# How to get a quick overview of technical material

1. Install the `read-fast` skill.
2. Invoke `/read-fast <source>`.
3. Provide a web URL, local file, PDF, or pasted text.
4. Ask the skill to keep only the main line, core concepts, and key conclusions.

The skill writes to `.reader/quick/` and targets a 2–10 minute read. Short sources are not forcibly cut; long sources keep the main line and point to `/read-standard` for deeper reading.
