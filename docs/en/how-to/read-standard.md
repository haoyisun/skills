# How to learn a piece of technical material deeply

1. Install the `read-standard` skill.
2. Invoke `/read-standard <source>`.
3. Provide a web URL, local Markdown or text file, PDF, or pasted text.
4. Ask the skill to follow the source order section by section, not to produce only a summary.

The skill writes to `.reader/deep/` and includes a reading map, prerequisites, glossary, section-by-section explanation, knowledge patches, possible correction notes, a synthesis, and self-check questions.

The language follows the current conversation; the skill asks when it is unclear.
