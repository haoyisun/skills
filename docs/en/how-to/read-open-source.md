# How to understand an open-source project

1. Install the `open-source-explorer` skill.
2. Invoke `$open-source-explorer`.
3. Provide a repository URL or local path.
4. State what you want to do: use it, contribute, debug, or learn a design.
5. Ask the skill to start from the README, manifest, public entry points, and execution paths instead of the project description alone.

The skill gathers evidence from code and tests before explaining architecture, data flow, and the smallest set of files relevant to your goal.
