# How to read a technical article

1. Install the `reader` skill.
2. Invoke `$reader`.
3. Provide the article URL, a local file path, or the pasted text.
4. State your goal: decide, explain, use, review, or learn.
5. Ask the skill to give a plain-language summary first, then explain unfamiliar terms, then list gaps and next steps.

Do not ask for a full page-by-page rewrite. Clarify the goal first so the skill can select what matters.
