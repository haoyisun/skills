# Install your first skill

## Prerequisites

- Node.js 18 or newer
- An AI tool that can invoke agent skills

## Install the whole project

```bash
npx skills add haoyisun/skills
```

The installer lists the available skills. You can install all of them or select only the ones you need.

## Install one skill

```bash
npx skills add haoyisun/skills --skill reader
```

After installation, invoke `$reader` in your AI tool and tell it what you want to read.
