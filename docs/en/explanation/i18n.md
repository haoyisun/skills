# Internationalization conventions

Reader maintains its documentation in English and Simplified Chinese so users can find the same information in either language.

## Root READMEs

- `README.md` is the English root README and the normative language.
- `README.zh-CN.md` is the Simplified Chinese mirror.
- Both READMEs keep the same section order and link to each other at the top.

## Documentation layout

```text
docs/
├── en/   English documentation
├── zh/   Simplified Chinese documentation
└── adr/  Architecture decision records
```

`docs/en/` and `docs/zh/` must keep identical relative paths. Add, delete, or rename pages in both language trees together.

## Link rules

- English pages use relative links such as `../reference/skills.md` and stay in the English tree.
- Chinese pages use relative links and stay in the Chinese tree.
- Cross-language links are used only when the page intentionally switches language.

## Content rules

- Both versions of a page state the same facts.
- Commands, file paths, and skill names stay identical.
- Prefer accuracy over literal word-for-word translation.
- English is the default; Simplified Chinese is a maintained mirror and should not lag behind for long.

Run `npm run check:i18n` to verify that both documentation trees have the same page structure.
