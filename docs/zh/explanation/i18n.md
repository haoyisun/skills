# 国际化文档约定

学者（Scholar）的文档同时维护英文和简体中文，目标是让使用者在两种语言里都能找到结构一致、内容准确的信息。

## 根 README

- `README.md` 使用英文，是根 README 的规范语言；
- `README.zh-CN.md` 是简体中文镜像；
- 两份 README 保持相同的章节顺序，并在顶部互相链接。

## 文档目录

```text
docs/
├── en/   英文文档
├── zh/   简体中文文档
└── adr/  架构决策记录
```

`docs/en/` 和 `docs/zh/` 必须保持完全相同的相对路径。每次新增、删除或重命名页面，都要同步维护两份语言。

## 链接规则

- 英文页面内部链接使用 `../reference/skills.md` 这类相对链接，并保持英文路径；
- 中文页面内部链接同样使用相对路径，并保持中文路径；
- 只有需要切换到另一语言时，才跨语言链接。

## 内容规则

- 同一页面在中英文里传达相同事实，不各自自由发挥；
- 示例命令、文件路径、skill 名称等代码内容保持一致；
- 翻译时优先保证准确，再追求自然；
- 英文是默认语言，中文作为维护中的镜像，不应长期落后。

运行 `npm run check:i18n` 可以检查两个文档树是否缺少对应页面。
