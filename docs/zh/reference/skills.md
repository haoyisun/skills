# 可用 skills

| Skill | 目录 | 用途 |
| --- | --- | --- |
| `read-project` | `skills/reading/read-project` | 读代码和文档，产出项目上手与架构指南 |
| `read-standard` | `skills/reading/read-standard` | 完整、深入地学习技术文章、博客、书籍或 PDF |
| `read-fast` | `skills/reading/read-fast` | 产出 2–10 分钟可读完的快速理解 |

每个 skill 的入口文件都是 `SKILL.md`，其中 `name` 必须与所在目录名一致。三套 skill 都带有 `disable-model-invocation: true`，只能主动触发。
