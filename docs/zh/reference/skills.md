# 可用 skills

| Skill | 目录 | 用途 |
| --- | --- | --- |
| `reader` | `skills/reading/reader` | 阅读技术文章、文档或密集文字材料 |
| `open-source-explorer` | `skills/reading/open-source-explorer` | 理解开源项目的架构、入口和数据流 |
| `skill-explainer` | `skills/reading/skill-explainer` | 理解一个 agent skill 的用途、触发条件和风险 |

每个 skill 的入口文件都是 `SKILL.md`，其中 `name` 必须与所在目录名一致。
