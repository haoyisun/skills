# 如何用学者学习一个新主题

1. 安装 `scholar` skill，并一起安装 `technical-diagrams`，这样它才能画图。
2. 调用 `/scholar <主题、来源或学习目标>`。
3. 回答关于目的、阅读时间和已有基础的问题。问题最多 5 个，每个都带一个可以直接采纳的建议答案。
4. 检查学习目标卡，改掉不对的地方，然后确认。
5. 学者会先检索并校验信源，再把材料写到 `.scholar/study/`。

深度档位决定产物形态：

- `quick 快读`：一篇概览，约 10 分钟读完。
- `guide 通学`：一份完整的单文件学习指南，1–3 小时读完。
- `mastery 精修`：多文件手册，适合数天到数周的学习，带可续写的计划。

以后想继续时，运行 `/scholar 继续 <会话目录>`，或者直接 `/scholar 继续`，它会挑最近修改且未完成的会话。
