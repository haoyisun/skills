# 如何理解并上手一个软件项目

1. 安装 `read-project` skill。
2. 调用 `/read-project <地址>`。
3. 地址可以是本地路径、仓库 URL、GitHub 链接或项目名称。
4. 如果 skill 问你的目标，告诉它是想运行、看懂架构、准备贡献，还是学习某个技术。
5. 让 skill 从 README、清单文件、入口点和关键执行路径开始，而不是只看项目简介。

skill 会产出到 `.reader/projects/`，并给出最小运行路径、架构地图、关键业务流程、术语表和文档与源码不一致的地方。

默认只做只读分析，不安装依赖、不构建、不跑测试。
