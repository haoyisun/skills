# 如何用 read-skill 读一个第三方 skill

1. 安装 `read-skill`，并一起安装 `scholarly-standards` 与 `technical-diagrams`。
2. 调用 `/read-skill <仓库地址、owner/repo、skill 名称或本地路径>`。
3. 你给的是一个本机已安装的 skill 名时，它会读那一份并明确告知；裸名称命中多个候选时，它只问一个问题，不替你猜。
4. 导读开头是一页卡片：它是做什么的、什么时候用、什么时候别用、怎么安装、最小示例、你会得到什么、有哪些坑。
5. 后面的章节展开场景、安装细节、用法变体、效果、组合、风险，并给出明确结论。

默认档位是 `full` 完整版；只想要一页卡片时说 `card`。含超过 12 个 skill 的仓库会写成"仓库总览 + 每个重点 skill 一章"。效果类说法会标注是实测、仓库声称，还是未验证。
