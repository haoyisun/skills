# 如何用 investigate 调研一个技术问题

1. 安装 `investigate`，并一起安装 `scholarly-standards` 与 `technical-diagrams`。
2. 调用 `/investigate <决策问题、技术、项目或概念>`。
3. 回答关于决策、交付形态和 grounding 的问题。问题最多 5 个，每个都带一个可以直接采纳的建议答案。
4. 检查任务卡，改掉不对的地方，然后确认。
5. investigate 会校验信源，只读决策需要的内容，再把产物写到 `.scholar/research/`。

档位决定产物形态：

- `brief` 简报：结论与关键证据，单文件。
- `plan` 方案：完整的设计方案与实施方案，单文件，是默认档位。
- `dossier` 深研：多文件产物，可以按章节续写。

每个方案都以决策点表收尾：列出还需要你拍板的选择，每条带建议、理由和拍板人。证据表把有来源的事实与方案自身的推演分开。
