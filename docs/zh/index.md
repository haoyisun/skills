# 学者

**学者**（Scholar）是一组面向 AI 工具的 skill，用来帮助人们更轻松地阅读、学习和理解技术资料。

读者（Reader）能力族负责阅读已经存在的材料：

- `/read-project`：理解并上手一个软件项目
- `/read-standard`：深入学透技术文章、博客、书籍或 PDF
- `/read-fast`：花 2–10 分钟快速看懂大意和关键概念

学者（Scholar）能力族负责按学习目标生产学习材料：

- `/scholar`：学习一个概念或知识体系，从十分钟的快速了解，到数周的系统手册
- `/investigate`：调研一个技术问题，产出经过校验的设计方案或实施方案
